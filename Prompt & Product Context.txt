PRODUCT CONTEXT — NEURAL PREDICTOS


Neural PredictOS is an AI-powered Material Demand & Procurement Intelligence platform designed for apparel manufacturing / RMG factories.


It is NOT an ERP replacement. It is an AI planning and intelligence layer that sits on top of existing ERP, Excel, CSV, and manufacturing systems.


Existing systems already contain:


- Production orders


- BOMs


- Inventory


- Purchase orders


- Suppliers


- Material requirements


- Historical consumption


- Production plans


Neural PredictOS uses this operational data to answer future-oriented planning questions:


1. What materials will we need over the next 1–6 months?


2. How much of each material will we need?


3. When will we need them?


4. What should we prioritize for procurement?


PRIMARY USERS:


1. Production Planner


2. Procurement Planner / Procurement Manager


CORE PRODUCT FLOW:


Data → AI Forecast → Future Shortage Detection → Risk & Priority → Procurement Recommendation → Human Decision → Production / Procurement Action


The product has 7 initial modules:


1. Data Integration — supporting module


   Import/connect ERP, Excel, CSV and manufacturing data.


2. AI Data & Master Management — supporting module


   Clean, standardize and organize materials, styles, BOM, suppliers, inventory and order data.


3. Neural SmartDemand Analytics — CORE FEATURE 1


   AI-powered forecasting of raw material and accessory demand for the next 1–6 months.


4. Neural Procurement Intelligence — CORE FEATURE 2


   Identifies future shortages, evaluates risk, prioritizes materials and recommends procurement quantity and timing.


5. What-If Analysis — supporting core feature


   Allows planners to test scenarios such as production increases, order changes and supplier delays.


6. Forecast Export — supporting module


   Export forecasts and insights for reporting and planning.


7. Manual Override & Feedback — supporting module


   Allows planners to adjust AI forecasts and provide feedback to improve future accuracy.


Both core features support two interaction modes:


MANUAL MODE:


The user selects filters, planning horizon, materials, styles, buyers, production forecasts, etc.


AGENTIC MODE:


The user enters a natural-language prompt and an AI agent automatically selects relevant data, performs analysis, forecasting/risk analysis and filtering.


IMPORTANT UX PRINCIPLE:


AI assists the planner; it does not replace the planner.


Every important AI-generated forecast or recommendation should remain reviewable and editable by the human user.


The home dashboard should therefore feel like a professional enterprise AI planning platform for an apparel factory — not a consumer chatbot.


Design language:

The UI should communicate:
